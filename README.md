# Alexander Scott portfolio

Professional portfolio for Alexander Scott, a former U.S. Marine Corps Sergeant and College of Charleston Computer Information Systems student.

Live site: https://a-scott-17.github.io/website-resume/

The site is a static GitHub Pages project built with semantic HTML, CSS, and a small JavaScript navigation enhancement. Content covers verified security experience, deployed local business websites, education, and current technical work.

## Local preview

Open `index.html` in a browser, or serve the repository with a local static server to check link and asset behavior.

## Public resume

The downloadable PDF lives at `resume/alexander-scott-resume.pdf`. Regenerate it with `scripts/build_resume.py` using Python and ReportLab after reviewing factual changes. The original master resume is source material and is not part of this public repository.
