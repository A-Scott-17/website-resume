# Alexander Scott portfolio

Professional portfolio for Alexander Scott, a former U.S. Marine Corps Sergeant and College of Charleston Computer Information Systems student.

Live site: https://a-scott-17.github.io/website-resume/

The site is a static GitHub Pages project built with semantic HTML, CSS, and a small JavaScript navigation enhancement. Content covers Marine Corps security experience, deployed client websites, a Python computer-vision project, education, awards, and contact information.

## Local preview

Open `index.html` in a browser, or serve the repository with a local static server to check link and asset behavior.

## Public resume

The downloadable PDF lives at `resume/alexander-scott-resume.pdf`. Regenerate it with `scripts/build_resume.py` using Python and ReportLab after reviewing factual changes. The original master resume is source material and is not part of this public repository. The portfolio and public PDF also reflect Alexander's direct September 2026 clarifications on service dates, WHCA duties, coursework, client projects, and recognition.

The AI-Assisted Physical Security Management System remains a concept with no implementation. Its planning notes are in `docs/ai-assisted-physical-security-system.md`; it is intentionally absent from the public portfolio and resume.
